## Design points worth keeping

- The legacy adapter must NOT await admission — only `exit`. A child that exits without ever emitting
  `spawn` still settles the way every current caller observes. Both paths attach a no-op `.catch()`
  to the promise they do not consume, or an unobserved denial surfaces as an unhandled rejection.
- `denyStart` is called from three places, and precedence matters because a promise keeps its FIRST
  settlement: synchronous spawn throw, then the `error` event (with the original error, so a
  never-admitted start rejects with what the runtime raised), then a catch-all in `cleanup()` with an
  uncoded `AGENT_SPAWN_NOT_ADMITTED`. Deny-after-resolve is a no-op, so an admitted start is never
  rewritten.
- Listeners are attached BEFORE the timeout is armed (they were after, in the landed code) so a child
  that spawns and dies in one tick cannot outrun them. There is a regression case for exactly that.
- Only `instanceof SpawnInvocationRefusal` enters the coded arm; a test spoof carrying own
  `code`/`layer` properties is rejected unchanged.
