## DoD, item by item

1. **Crash injection at every boundary.** 10-entry literal boundary list, one real
   `SIGKILL`ed child per entry, each on its own `mkdtempSync` database. Every case asserts the
   `BOUNDARY:<name>` marker AND non-zero exit (never a signal name), then
   `PRAGMA integrity_check === "ok"`, `foreign_key_check` zero rows, a schema-validating
   `SqliteEventStore.open` whose `getHealth()` is compared as `{quickCheck:"ok",violations:0}`
   (not a bare "did not throw"), exact row counts across `domain_events`/`outbox_messages`/
   `inbox_receipts`, and a `rebuildProjection` reconciliation proving the durable row is a
   whole-prefix fold. Matrix asserts `covered.length === BOUNDARIES.length`, `> 0`, and
   `new Set(covered).size === length`, so a degenerate zero-spawn run fails. FUZZ additionally
   asserts `new Set(survivors).size > 2` — a fuzz that always died at the same statement cannot
   masquerade as six cases.
2. **Byte-identical rebuild.** Digest equality is the byte-identity proof (canonical encoder
   key-sorts and length-frames). Asserted rebuild digest === incremental digest === durable
   `state_digest`, plus `toStrictEqual` on the state, over the curated history, 8 fixed seeds,
   and the edges a generator rarely produces (empty ledger, single event, one commit at
   `MAX_EVENTS_PER_COMMIT` spanning 3 pages, and an exotic state carrying `-0`, NaN, ±Infinity,
   bigints, nesting and two key insertion orders). Sweep asserts `generated > 0`,
   `committed === generated`, distinct digests `> 1`, and `upcastEvents > 0`. The key-order
   property is asserted against production `canonicalProjectionState`, including that it does
   NOT collapse `-0` onto `0` — otherwise the equality would prove nothing.
3. **Combined idempotence.** Redelivery across a crash asserts `ALREADY_APPLIED` +
   `deduplicatedBy === "INBOX"` + unchanged digest, with the stale-`expectedVersion` arm pinned
   separately to `EXPECTED_VERSION_CONFLICT` — two layers, both named. Restart mid-rebuild
   (`REBUILD_PROJECTIONS_UPDATE` skip 2, durable row left at 3 over a 6-event ledger) resumes to
   exactly the `NONE`-mode uninterrupted reference row, and a third run still changes nothing.
   Rebuild→relay→rebuild matches a cold rebuild. Both CAS-loss arms refuse
   `PROJECTION_REBUILD_STATE_CONFLICT`, with `detail` pinning WHICH guard answered
   ("runs ahead of" vs "compare-and-set").
4. **Gate + ownership.** `git show --stat 272a755` contains only
   `packages/store/src/projections/**` — no debug, probe, scratch, or evidence files.
   `git status --porcelain -- packages/store` clean at review end; nothing staged.
