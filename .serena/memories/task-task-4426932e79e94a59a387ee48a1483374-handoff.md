## Refactor-only proof technique (reuse this)

Do not rely on "tests pass" alone for a pure-move refactor. Cheap, decisive checks:

- **Brace-matched body comparison** vs `git show HEAD:<file>` — proved 26 function bodies
  byte-verbatim. Caveat: for a function whose return type is an inline object literal
  (`function f(): { readonly a: X }`), the first `{` after the name is the *type*, not the body —
  compare that one by text slice instead.
- **Error-literal tally**: regex `/"(PHASE0_[A-Z0-9_]+)"/g` over old vs new file sets, compare
  per-code counts. Caught nothing here, would catch a dropped or duplicated failure branch.
- **Public surface**: confirm `index.ts` byte-unchanged, `node --experimental-strip-types` import
  of the index to list runtime exports, and `tsc --noEmit false --declaration --emitDeclarationOnly
  --outDir node_modules/.cache/<probe>` to read the emitted `.d.ts`. Delete the probe dir before
  committing.
