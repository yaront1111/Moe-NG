# macOS runner boundary surface decision

For the runner portability boundary, retain the frozen neutral nine-code `PLATFORM_ERROR_CODES` vocabulary and distinguish darwin refusals by the exact `PLATFORM_MACOS` layer plus boundary. Do not call or import Linux classifiers merely because payload shapes match.

Use the landed three-responsibility split (facts, single-boundary envelope classifier, whole observation) with exact one-line LF `.js` bridges. The existing runtime-entrypoint test already discovers every runtime TS module, checks its bridge bytes, and imports the bare `@moe/runner` root under real Node; new OS modules normally need no edit to that test.

Exact-record hostility is shared contract behavior: `Reflect.ownKeys`, enumerable own data descriptors, no accessor reads, and reflection exceptions fail closed. Caller-supplied darwin facts can prove deterministic classification on Windows, but never constitute host-native macOS conformance.
